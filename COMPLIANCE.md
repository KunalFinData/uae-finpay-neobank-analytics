\# Compliance \& Regulatory Context



This project is a fictional portfolio exercise built to demonstrate analytics and data engineering capability for the UAE fintech sector. It references real UAE regulatory frameworks for context and realism, but does not constitute compliance advice or an actual compliance implementation.



\## Referenced Frameworks

\- \*\*CBUAE AML/CFT/CPF Guidance Package (April 2026)\*\* — informs the fraud/anomaly detection framing used across the UAE FinPay portfolio

\- \*\*PDPL (UAE Federal Decree-Law No. 45 of 2021, Personal Data Protection Law)\*\* — informs the data handling note below



\## PDPL Note

All ML models in this project operate on anonymised `customer\_id` values only. No personally identifiable information (names, Emirates ID, phone numbers, physical addresses) is used, stored, or processed at any stage. This reflects a purpose-limitation and data-minimisation approach consistent with PDPL Article 4 principles, applied here for portfolio demonstration purposes.



\## Scope Disclaimer

This is not a regulated financial product and was not built for, or reviewed by, an MLRO, compliance officer, or legal counsel. It should not be used as a template for actual regulatory submissions. Regulatory references exist solely to demonstrate awareness of the operating environment a UAE fintech data analyst would work within.
